Options

Time between scrolls while collecting. Default is 2200. If X rate-limits you, raise it.
Re-download all media keeps your bookmarks but forgets which media was saved, so the next run fetches every photo and video again. Use it if media files went missing or the gallery shows blanks. Reset library forgets everything and starts over.

This extension runs entirely on your machine. Nothing leaves it: no servers, no telemetry, no tracking.
